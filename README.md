## Featured Projects

### [Synoptiq](https://github.com/abhiramaab)

A productivity platform backend that aggregates workspace services into automated workflows.

- **Stack:** Java, Spring Boot, PostgreSQL, Google OAuth 2.0, REST APIs
- Implemented Google OAuth 2.0 authentication, external service integrations (Gmail & Calendar), and background event processing.

---

### [RouteSphere](https://github.com/abhiramaab)

A logistics and route dispatch management backend built for reliable order tracking and operations.

- **Stack:** Java, Spring Boot, PostgreSQL, Spring Security, JWT
- Engineered secure RESTful APIs with role-based access control (RBAC), stateless JWT authentication, and transactional order routing.

---

### [WorkBoard](https://github.com/abhiramaab)

An enterprise project management backend modeling multi-level corporate hierarchies.

- **Stack:** Java, Spring Boot, Spring Data JPA, PostgreSQL, Hibernate
- Architected relational data models for departments, tasks, and employees with optimized JPA fetch strategies to prevent N+1 query overhead.
